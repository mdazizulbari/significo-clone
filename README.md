# Significo Clone
A clone of the Significo website, built to practice advanced frontend techniques with smooth scrolling and animations, following tutorials from Sheryians Coding School. This project showcases a modern, visually engaging web experience.

## 🌐 Live Project
[View Significo Clone Live](https://mdazizulbari.github.io/significo-clone/)

## 🛠 Technologies Used
- **Frontend**: HTML, CSS, JavaScript (ES6)
- **Libraries**: GSAP, Locomotive Scroll
- **Tools**: Git, npm

## ✨ Core Features
- **Smooth Scrolling**: Implemented with Locomotive Scroll for a seamless user experience.
- **GSAP Animations**: Dynamic animations for page transitions and element interactions.
- **Responsive Layout**: Adapts to various screen sizes with a mobile-first approach.
- **Modern Design**: Clean, professional aesthetic inspired by Significo’s branding.

## 🚀 How to Run Locally
1. **Clone the Repository**:
   ```bash
   git clone https://github.com/mdazizulbari/significo-clone.git
   ```
2. **Navigate to the Project Directory**:
   ```bash
   cd significo-clone
   ```
3. **Install Dependencies**:
   ```bash
   npm install
   ```
4. **Serve the Project**:
   - Use a local server (e.g., Live Server extension in VS Code) or run:
   ```bash
   npx serve
   ```
5. Open the provided local URL (e.g., `http://localhost:3000`) in your browser.
